# Containers Benchmark
This is the little program I used to find the numbers that I presented at CppCon 2026 in my Back to Basics: Containers talks.

A class diagram showing what this program does is [here](ClassDiagram.pdf).

## Disclaimers

This program only exercises one particular use case. I will reiterate the point of my talk, which is that you must measure your performance and choose and adjust your container accordingly.

This uses a pre-release, not for real use version of std::inplace_vector. Your library may differ.
